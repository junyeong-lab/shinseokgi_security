# KISA Vulnerability Checker

2026 주요정보통신기반시설 기술적 취약점 분석·평가방법 상세가이드의 UNIX 점검 항목을 기준으로, **Rocky Linux 환경에서 읽기 전용으로 점검하는 Python CLI**입니다.

> 개발 상태: U-01~U-06, U-16, U-18 초기 코드 구현 및 CI 단위 테스트 수행. 실제 Rocky Linux 9.8의 최신 코드 실환경 실행과 KISA 기준 대비 최종 판정 검증은 **미완료**입니다. 구현 완료를 보안 적합 판정으로 해석하면 안 됩니다.

## 항목별 상태

| 항목 | 내용 | 현재 수준 |
| --- | --- | --- |
| U-01 | root 계정 원격 접속 제한 | SSH/Telnet 초기 수집, 보수적 수동확인; 실서버 초기 실행 확인 |
| U-02 | 비밀번호 관리정책 설정 | PAM, pwquality, pwhistory, 계정 사용 기간 읽기 전용 수집; 실서버 최신 코드 미검증 |
| U-03 | 계정 잠금 임계값 설정 | faillock.conf/PAM 조회 및 보수적 판정; 실서버 미검증 |
| U-04 | 비밀번호 파일 보호 | /etc/passwd의 shadow 참조 및 /etc/shadow 존재 확인; 실서버 미검증 |
| U-05 | root 이외 UID 0 금지 | 로컬 /etc/passwd 기준 UID 0 중복 점검; 실서버 미검증 |
| U-06 | 사용자 계정 su 기능 제한 | su 실행 파일 그룹 권한·ACL/PAM pam_wheel 설정을 최소 메타데이터로 수집; 실서버 미검증 |
| U-16 | /etc/passwd 파일 소유자·권한 | 소유자 root, 권한 0644 허용 비트 기준 메타데이터 점검; 실서버 미검증 |
| U-18 | /etc/shadow 파일 소유자·권한 | 소유자 root, 권한 0400 허용 비트 기준 메타데이터 점검; 파일 내용 미수집·실서버 미검증 |

## 실행

Python 3.9 이상에서 시스템 설정을 바꾸지 않고 실행합니다.

```bash
python3 main.py
```

JSON 보고서가 필요하면 다음 명령으로 별도의 신규 파일을 생성합니다.

```bash
python3 report_json.py
```

`reports/assessment_*.json`에 결과가 저장됩니다. 기존 파일을 덮어쓰지 않고 Linux에서는 가능할 때 0600 권한을 사용합니다. 생성 보고서에는 호스트명/계정명/설정 정보가 들어갈 수 있으므로 외부 공개 전에 검토하십시오. 보고서는 Git 추적에서 제외됩니다.

## 자동 테스트

```bash
python3 -m compileall -q main.py checks tests report_json.py
python3 -m unittest discover -s tests -v
```

GitHub Actions에서는 Python 3.9와 3.12로 테스트합니다. Mock/fixture 테스트는 실제 서버 설정이나 인증 동작을 입증하지 않습니다.

## 안전 및 제한

- **수집 전용**: 계정 잠금, 비밀번호, SSH, PAM, 방화벽, 서버 설정을 자동 변경하지 않습니다.
- **비밀번호 비수집**: U-04는 원문이나 암호화 해시를 결과에 포함하지 않습니다.
- **범위 구분**: U-05는 로컬 /etc/passwd 기준입니다. LDAP/SSSD/NSS 외부 계정의 전수 검증을 의미하지 않습니다.
- **U-06 제한**: PAM 그룹 제한을 발견해도 include/제어 흐름을 확인하기 전에는 수동확인으로 남깁니다. su 파일의 그룹 전용 실행 권한은 symlink 및 확장 ACL 유무까지 확인한 경우에만 양호로 분류합니다.
- **U-16/U-18**: 파일 내용은 읽지 않고 소유자·권한 비트만 검사합니다. KISA의 '0644 이하', '0400 이하'는 허용 비트 마스크로 검사하여 실행 권한·특수 권한을 놓치지 않습니다.
- **보수적 판정**: PAM 적용 경로나 인증 상태 확인이 충분하지 않은 경우 '수동확인'을 유지합니다.
- **서버 반영 전 검증**: 로컬 코드와 서버 배포본 간 버전 동기화, 실행 확인, 증빙 확보가 별도로 필요합니다.
- **수정/조치**: 취약점 조치 기능은 현 단계에 포함되지 않으며, 향후 사용자 승인·백업·복구 절차를 마련한 후 진행할 예정입니다.

프로젝트 진행 기록은 노션의 **신석기백화점 SI 프로젝트**에 관리합니다.
